A studio catalogue photograph of an impossible gadget: LOOP-1, a white power strip that plugs into itself. Its own cable loops out of one end in a smooth curve and seats back into the strip's own socket, while a small desk lamp plugged into another socket glows warm amber — proof the impossible power works. The whole scene is hand-drawn in HTML/CSS/SVG and rendered with headless Chromium and real fonts as a 1024×1024 PNG, with a soft key light, a gentle surface shadow, and a single discreet catalogue caption.

## Run it

```sh
node main.ts
```

This writes `entry.png` to `/output` (or `$MAKEFUN_OUTPUT_DIR` when set), then reads it back and verifies it byte for byte. Requires Node 22+ and a headless Chromium (Playwright's cached build, or set `CHROMIUM_PATH`).
